Is Sub Club worth joining?

For codes, yes, because codes on this page require sign-in. For savings alone, expect a small return, not a large one.

Sub Club is Subway's loyalty program. Its current terms, updated April 1, 2026, work like this: 10 points per $1 spent, 400 points worth $2 in Subway Cash, about 5% back, plus 250 bonus points when you join, and a birthday surprise if your birthday is saved in your profile. Member-only app offers are also part of the program.

Two things to know. First, the old every 4th footlong free benefit was retired on April 1, 2026. Several coupon sites still show it. It is dead. Second, Subway's terms do not say whether you earn points on orders placed with a promo code, so this page will not guess. Points expire after 6 months with no account activity, and any Subway Cash above your bill total is forfeited when you redeem it.

How do you use a Subway promo code?

Follow this order, because the most common failure is the order of the steps, not the code itself.

  1. Sign in to Sub Club first. Without sign-in, checkout stops at "Offer only available to Sub Club members."
  2. Select your Subway location in the app or on the website first.
  3. Add the qualifying items the promotion requires.
  4. Continue to checkout and look for the promo code field there. There is no promo code box in the shopping bag.
  5. Enter the code and check your order total. The discount showing in the total is the real confirmation, not the code being accepted.
  6. If it fails, work through the troubleshooting below before assuming the code is dead.

Why is your Subway promo code not working?

Work through these in order. Most failures are one of these, not a dead code.

You are not signed in

Every code on this page requires Sub Club sign-in. Guest checkout accepts the code field but stops with "Offer only available to Sub Club members. Sign in here or Join now." Sign in, then try again.

Code says invalid

Check, in order: whether you are signed in, whether you are on the right price tier for your store, whether the code expired, the current reported set runs through November 15, 2026, and whether your restaurant participates.

Code is accepted but no discount appears

Check whether your cart has the qualifying items, whether you met any minimum, whether an excluded sub is in the cart, Big Hot Pastrami, The Beast, 5 Meat Italian, and Garlic Roast Beef are commonly excluded, and whether another discount is already applied. One promo code per order.

Code works at a different Subway but not yours

This is the tier restriction, not a fake code. Try the next tier up, or the next-closest location.

The code field itself is missing

There is no promo code box in the shopping bag. If you are looking for it in the bag, you are looking in the wrong place. Look at checkout.

Dead codes to stop trying

BOGO50, buy one footlong and get the second 50% off, expired October 2, 2026. Do not confuse it with the separate BOGO free footlong wallet reward through November 8, 2026, which has no public code. 699FL is reported invalid. The every 4th footlong free benefit was retired April 1, 2026.

Frequently asked questions about Subway coupons

What is the best Subway deal right now?

The $4.99 Sub of the Day, because it needs no code and no account. For a footlong, try the footlong codes in tier order and let your store decide the price.

Why does a Subway promo code work at one location but not another?

Subway stores are franchises and each store honors one price tier of the monthly code set. A rejection usually means your store is on a higher tier, so step up one tier and try again.

Can I combine a Subway promo code with Sub Club rewards?

Only one promo code per order. Subway's terms do not say whether points are earned on promo-code orders, so this page does not guess.

Can Subway promo codes be used for delivery?

Usually not. App and website codes are generally excluded from delivery, so check your delivery platform's own promotions instead.

How can I tell whether a Subway promo code is actually active?

The discount appearing in your order total is the test. Check the expiry too: the current reported code set runs through November 15, 2026.

Is the every 4th footlong free deal still available?

No. Subway retired it on April 1, 2026. The current program earns 10 points per $1, with 400 points worth $2 in Subway Cash.
